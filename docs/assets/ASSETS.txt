Brand assets for Project Satori and DER Security.

satori.png            Satori lockup, dark text -- for light backgrounds
satori-dark.png       Satori lockup for dark backgrounds -- the official
                      dark export, with its uniform background lifted to
                      transparency so the mark floats on any dark theme
satori-mark.png       square Satori mark, charcoal on transparency --
                      the docs-site favicon
satori-mark-dark.png  the same mark in the brand cream, for dark
                      surfaces -- the docs-site header logo
dersec-dark.png       DER Security lockup, dark text
dersec-white.png      DER Security lockup, white text

The README pairs the light/dark variants with <picture>
prefers-color-scheme sources, so the banner is legible in both GitHub
themes.

Referenced by absolute raw.githubusercontent URL rather than by relative
path. `pyproject.toml` sets `readme = "README.md"`, which makes the README
the PyPI long description, and a relative path there resolves against
pypi.org and 404s. The absolute form renders on both GitHub and PyPI, so
it is the one that works everywhere the README is shown.
