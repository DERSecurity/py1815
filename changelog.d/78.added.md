**The master looks after an outstation without being asked (#78).** On connecting, and
when an outstation reports that it restarted, it stops unsolicited reporting and reads
everything. It clears the restart indication, sets the clock when the outstation asks,
fetches events when a response says some are waiting, reads everything again after an
event buffer overflow, and enables unsolicited reporting for the classes it is given.
Each is a task of `Tasks` that can be turned off, and `manual=True` turns off every one
along with confirmations. No task commands an output, and none is made due by the answer
to its own request. A connection that was made and then lost is made again, every
`reconnect` seconds. `idle()` waits for what is due, and an exchange a task made says so
in `task`. `Loopback` takes `tasks` and has `start()`. The JSON service takes `tasks`,
`manual` and `reconnect` when an outstation is added, has an `idle` operation, and
reports each outstation's tasks; the command line has `--manual`, `--unsolicited` and
`--reconnect`; and the console shows what is done unasked and logs each time it is.
