**A Level 4 outstation reports binary and analog output events, and the master decodes command events (#115).** With `level=4`, an output whose value or flags change raises a group 11 or group 42 event, in the class of the input paired with it, which class 1, 2 and 3 polls and reads of the group return, with overflow handling as for the inputs. Class 0 then carries the status of each output that reports events, as the subset tables require when output events are reported. Reads of groups 13 and 43 are answered with a null response, since command events are not generated. The Device Profile lists the new groups and each output's class. The master decodes groups 13 and 43. Levels 2 and 3 and the default answer as before.
