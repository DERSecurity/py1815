**The master sends the requests of Subset Level 3 and Level 4 (#119).** `read_group` reads a group by a named variation, by a range of points or by a list of indices; `read_time` and `read_indications` read the time (group 50) and the internal indications (group 80); `assign_class` sends ASSIGN_CLASS for named points, double-bit inputs among them; `read_deadbands` and `write_deadbands` read and write analog input deadbands (group 34); `read_attributes` and `write_attribute` read and write device attributes (group 0). Each is on the Python master, in the service and its HTTP API and in the OpenAPI document, and each is refused before it is sent when the outstation is set to a lower level.

**The console and `py1815-master evaluate` cover the requests of Subset Level 3 and Level 4 (#119).** The console's Commands tab reads by variation, by range or by list, reads the time, the internal indications, the device attributes and the deadbands, and with `--allow-control` assigns event classes and writes deadbands and attributes. The `subset` set of `py1815-master evaluate` checks what a Level 3 and a Level 4 outstation answer.
