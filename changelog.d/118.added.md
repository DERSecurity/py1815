**The master is given each outstation's subset level, and sends no request above it (#118).** Set `level` to 2, 3 or 4 when adding an outstation, in the configuration file, or with `--level`. It is 2 when not given. A request above the level raises `AboveSubsetLevel` and is not sent, as IEEE 1815-2012 14.7.2 requires of a master.
