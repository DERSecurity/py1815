**`OutstationServer` and `Session` take a `request_observer`, called with a
`RequestRecord` for each request the outstation handles and each unsolicited
response it sends (#104).** The record carries the connection the request
arrived on, the link addresses, the function code, the request octets and the
response sent back, so an application embedding the outstation can log or
forward the traffic it serves. Frames the session drops are still reported as
anomalies and are not reported again.
