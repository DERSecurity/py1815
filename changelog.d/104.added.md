**`OutstationServer` and `Session` take a `request_observer`, called with a
`RequestRecord` for each request the outstation handles and each unsolicited
response it sends (#104).** The record carries both ends of the connection the
request arrived on, the link addresses, the function code, the request octets
and the response sent back, so an application embedding the outstation can log
or forward the traffic it serves. Frames the session drops are still reported as
anomalies and are not reported again.

**`py1815.traffic` turns the outstation's request records and the master's
exchanges and unsolicited responses into the message bodies and envelopes a
Wireshark-based network monitor publishes for captured DNP3 traffic (#104).**
An application can publish its own traffic on the monitor's channel without
conversion code. The envelope type is in `py1815.envelope`, copied from the
published format with no new dependency. The bodies match a recording of the
monitor's output key for key, including where it follows the dissector rather
than the standard. The master's `Outstation.connection` gives the two ends of the
connection to fill them, and `py1815.decode.decode_blocks` reads a body header by
header.
