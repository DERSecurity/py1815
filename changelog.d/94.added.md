**A conformance harness the project did not write runs the certification procedures (#94).**
Continuous integration runs [dnp3c](https://github.com/stepfunc/dnp3c), Step Function I/O's
conformance test harness, against a Subset Level 2 configuration of the outstation, and
[Conformance run with dnp3c](https://dersecurity.github.io/py1815/conformance/) says how every procedure ends and why.
The job compares each run with a record, so a procedure that starts to fail or starts to
pass is noticed. `interop/dnp3c/`, the test program that links the harness, is licensed
under the GNU General Public License, version 3 only; nothing in it is part of the
library, the wheel or the source distribution.
