**A Level 3 or 4 outstation answers four more reads.** It reads the packed binary input variation (group 1 variation 1, answered with flags), 16-bit frozen counter events (group 23 variation 2, answered in 32 bits), the current time (group 50 variation 1) and the internal indications (group 80 variation 1, indexes 0 to 15). Level 2 and the default refuse them as before. `Session` takes `time_source` and `indications_read` for the last two. The master reads group 80 variation 1 in a response. (#110)

**A Level 3 or 4 outstation reports counter events when a counter's flags change.** A counter that loses or regains communication raises a group 22 event with its count and new flags, reported in the class of its frozen counter events by class polls, unsolicited responses and reads of group 22 variations 0, 1 and 2, all in variation 1. A change in value raises none, as IEEE 1815-2012 11.9.5.2 and TB2016-003b Table 12-49 footnote o allow. The Device Profile states the counter event class and that value changes are not reported. Level 2 and the default report no counter events, as before. (#110)
