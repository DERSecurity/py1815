**The Rust interop peers stay on dnp3 1.7.x (#147).** dnp3 1.8.0 changes the crate's license to forbid using it to test another DNP3 implementation, which is what the Rust master and outstation do. Both now require `~1.7`, Dependabot ignores dnp3 1.8 and later, and the license links point at the 1.7.0 text.
